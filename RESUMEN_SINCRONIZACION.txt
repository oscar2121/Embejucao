═══════════════════════════════════════════════════════════════════════════════
 🔧 CAMBIOS TÉCNICOS PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

1️⃣  PANTALLA DE CONFIGURACIÓN INICIAL
    • Si ipConfigured === false, muestra pantalla setup
    • Usuario ingresa IP del servidor
    • Se prueba conexión antes de continuar
    • IP se guarda en AsyncStorage para sesiones futuras

2️⃣  SINCRONIZACIÓN AUTOMÁTICA
    • useEffect con dependencia [ipConfigured]
    • Llama sincronizar() cada 5 segundos
    • GET /api/pedidos/date/HOY obtiene todos los del día
    • Se ejecuta al conectar y luego cada 5s

3️⃣  ACTUALIZACIÓN INMEDIATA
    • Al crear pedido: POST + sincronizar()
    • Al cambiar estado: PUT + sincronizar()
    • Los cambios aparecen al instante en el otro celular

4️⃣  IP DINÁMICA EN TODOS LADOS
    • enviarPedido() usa http://${serverIP}:3001/api
    • actualizarItem() usa http://${serverIP}:3001/api
    • sincronizar() usa http://${serverIP}:3001/api

5️⃣  INDICADOR DE CONEXIÓN
    • 🟢 Verde = conectado, sincronizando
    • 📡 Rojo "Sin conexión" = desconectado
    • Se actualiza en tiempo real

6️⃣  RECONFIGURABLE FÁCIL
    • Botón ⚙️ en esquina superior derecha
    • Vuelve a pantalla de configuración
    • Sin necesidad de reiniciar app

═══════════════════════════════════════════════════════════════════════════════
 🚀 CÓMO INICIAR
═══════════════════════════════════════════════════════════════════════════════

PASO 1: Inicia el servidor
   $ npm run server
   
   Esperado:
   ✅ Tablas inicializadas
   🚀 Servidor corriendo en http://localhost:3001
   📡 API disponible en http://localhost:3001/api
   ✅ Base de datos conectada

PASO 2: Abre la app en PRIMER celular
   • Aparece: ⚙️ Configuración del Servidor
   • Ingresa IP de tu computadora (ej: 192.168.1.100)
   • Toca: Conectar →
   • Espera ✅ "Conectado al servidor"

PASO 3: Abre la app en SEGUNDO celular
   • Repite PASO 2 con MISMA IP
   • Ambos deben mostrar 🟢 verde

PASO 4: Prueba sincronización
   • Celular 1 (Mesero): Crea pedido
   • Celular 2 (Chef): Debe verlo en <5 segundos
   • Celular 2: Cambia estado a "Preparando"
   • Celular 1: Debe actualizarse automáticamente


═══════════════════════════════════════════════════════════════════════════════
 🔄 ARQUITECTURA DE SINCRONIZACIÓN
═══════════════════════════════════════════════════════════════════════════════

                         SERVIDOR (Port 3001)
                        SQLite: embejucao.db
                                  │
                    ┌─────────────┼─────────────┐
                    │             │             │
              GET /pedidos   POST /pedidos  PUT /pedidos/:id
            (cada 5 segundos)   (al crear)   (al cambiar estado)
                    │             │             │
         ┌──────────┴──────┐      │        ┌────┴──────────┐
         │                 │      │        │               │
      MESERO 📱          CHEF 📱  │     MESERO 📱       CHEF 📱
      Celular 1        Celular 2  │     Celular 1     Celular 2
      (Phone A)        (Phone B)   │     (Phone A)     (Phone B)
         │                 │       │        │               │
      AsyncStorage    AsyncStorage │    AsyncStorage   AsyncStorage
      pedidos         pedidos      │    pedidos        pedidos
      (cache local)   (cache local)│    (cache local)  (cache local)
         │                 │       │        │               │
         └─────────────────┴───────┴────────┴───────────────┘

Flujo:
   1. MESERO crea pedido → POST server + AsyncStorage
   2. CHEF sincroniza (cada 5s) → GET server
   3. CHEF ve nuevo pedido → AsyncStorage + UI
   4. CHEF cambia estado → PUT server
   5. MESERO sincroniza → GET server
   6. MESERO ve cambio → AsyncStorage + UI

═══════════════════════════════════════════════════════════════════════════════
 🐛 TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

"❌ No puedo conectar"
   □ Verifica IP en cmd: ipconfig
   □ Verifica servidor: npm run server
   □ Verifica WiFi: ambos en misma red

"Sincronización lenta (>5s)"
   □ Acércate al router
   □ Reinicia servidor
   □ Verifica WiFi no esté congestionada

"Se desconecta constantemente"
   □ La IP puede cambiar
   □ Asigna IP estática a computadora
   □ O reconfigurable con ⚙️

"Los datos no se sincronizaron"
   □ Revisa indicador: ¿Está verde?
   □ Si es rojo: reconecta
   □ Si error persiste: reinicia app
